## Bugs / Issues Ranked by Severity

### Critical (blocks core functionality)

1. **S-1 / D-1 / K-1: CORS preflight failures on `semantic-search` and `podcast-discover` Edge Functions.** Both functions reject preflight `OPTIONS` requests from `http://localhost:5173`. This makes semantic search (the app's primary value proposition) and discover (the exploration layer) entirely non-functional in local development. The Podcast Index search via the `podcast-episodes` Edge Function works fine (it successfully returned 12 results for "Joe Rogan"), suggesting the CORS headers are correctly configured on some functions but not `semantic-search` and `podcast-discover`.

### Major

2. **S-2: `public.search_history` table missing from PostgREST schema cache.** Table may exist in the database but is not exposed to the Supabase JS client. Every `/search` page load produces console errors.
3. **E-1 / E-2: Fake UUID routes silently redirect to home.** No user-facing error message when navigating to a non-existent KB or podcast. The console logs the error but the user sees the home page with no explanation.
4. **E-3: No 404 page for unknown routes.** `/nonexistent-route` renders a blank main content area inside the layout. No "page not found" messaging.

### Minor

5. **S-3: Search URL params not synced.** Query and tab are not written back to the URL, so search state is not bookmarkable or shareable.
6. **D-2: Discover page error has no retry button.** Unlike the semantic search error, which shows "Retry", discover errors require a full page reload.
7. **P-1: Static resource 404s on profile page.** Non-blocking but produces console noise.
8. **Home page: nested `<button>` elements in KBCard.** React DOM warning about `<button>` inside `<button>`. The KB card's delete button is nested inside the clickable card button. Should use a `<div>` with `role="button"` for the outer element or restructure.
9. **Home page: `playback_progress` table missing from schema cache.** Same pattern as search_history -- table not exposed via PostgREST.

- **Search page UI is well-designed.** Two-tab layout is clean, filter panel is intuitive, scope pills and threshold slider are useful power-user features.
- **Podcast Index search is functional and fast.** "Joe Rogan" returned 12 results in ~3 seconds with artwork, metadata, and episode counts.
- **Command palette is polished.** Supports filtering, `?` semantic search mode, keyboard navigation hints, and shows both KBs and podcasts. Escape closes cleanly.
- **OPML import modal is well-structured.** Clear instructions, correct file type restrictions, drag-and-drop zone.
- **Auth page is clean.** Magic link + Google + GitHub auth options with PodBrain branding.
- **Profile page has all expected sections.** Account info, sign out, subscriptions management, danger zone.
- **Keyboard shortcuts work correctly.** Both `/` and `Ctrl+K` function as designed.
