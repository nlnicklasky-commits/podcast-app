## Fixes Applied

### Fix 1: 404 catch-all route
**File:** `src/App.jsx`
- Added `Link` to import from `react-router-dom`
- Added `<Route path="*">` as last route inside protected routes block, rendering a centered "Page not found" message with a Link back to `/`

### Fix 2: Client-side UUID validation
**Files:** `src/pages/KnowledgeBase.jsx`, `src/pages/PodcastDetail.jsx`
- Added `UUID_RE` constant to both files
- KnowledgeBase.jsx: validates `id` at start of `load()` before Supabase query; shows "Knowledge base not found" with home link when `kb` is null (replaces bare `return null`). Added `Link` import.
- PodcastDetail.jsx: validates `podcastId` and `kbId` (if present) at start of `load()` before Supabase query; shows "Podcast not found" with home link when `podcast` is null (replaces bare `return null`). Added `UUID_RE` constant.

### Fix 3: Nested button HTML violations
**Files:** `src/pages/Home.jsx` (KBCard), `src/pages/KnowledgeBase.jsx` (PodcastRow), `src/pages/SearchPage.jsx` (history pills)
- Changed outer `<button>` to `<div role="button" tabIndex={0}>` with `onKeyDown` handler for Enter/Space
- Added `cursor-pointer` class to preserve visual affordance
- Inner delete/remove buttons remain as `<button>` with existing `e.stopPropagation()`
- Closing tags changed from `</button>` to `</div>`

### Fix 4: Image onError fallback
**Files:** `src/pages/Home.jsx`, `src/pages/KnowledgeBase.jsx`, `src/pages/PodcastDetail.jsx`, `src/pages/SearchPage.jsx`
- Added `onError={(e) => { e.currentTarget.style.visibility = 'hidden' }}` to all artwork `<img>` tags
- Home.jsx: recent podcasts row thumbnail
- KnowledgeBase.jsx: PodcastRow thumbnail
- PodcastDetail.jsx: header artwork
- SearchPage.jsx: selected show artwork + show list artwork

### Fix 5: OS-aware keyboard hint
**File:** `src/components/Layout.jsx`
- Replaced hardcoded `⌘K` with inline ternary using `navigator.platform || navigator.userAgent` to detect Mac/iOS
- Shows `⌘K` on Apple devices, `Ctrl+K` on all others

### Fix 6: Search URL param sync
**File:** `src/pages/SearchPage.jsx`
- Changed `const [searchParams]` to `const [searchParams, setSearchParams]`
- Added `useEffect` that syncs `debouncedQuery` and `activeTab` to URL params (`q` and `tab`)
- Uses `{ replace: true }` to avoid polluting history
- Only updates when values actually differ from current params to avoid loops
- Omits default values from URL (empty query deletes `q`, `transcripts` tab deletes `tab`)

### Fix 7: Clickable transcript timestamps
**File:** `src/pages/PodcastDetail.jsx`
- Passed `audioRef` prop to `TranscriptView` component
- Added `useSearchParams` inside `TranscriptView` for URL updates
- Changed timestamp `<span>` to `<button>` with click handler that:
  - Sets `audioRef.current.currentTime` to segment start and calls `play()`
  - Updates URL with `?t=<seconds>` via `setSearchParams` with replace
- Styled with `cursor-pointer`, `hover:underline`, transparent background, no border
